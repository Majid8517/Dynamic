This file maps the manuscript method to executable code so reviewers can trace each claim.

## Scientific boundary

This package is the executable specification of the method. It does **not** retroactively prove that every historical manuscript result was generated by this exact implementation. A historical value should be attributed to this code only after controlled re-execution with the corresponding data split, checkpoint, evaluator, hardware/backend, and archived logs.
